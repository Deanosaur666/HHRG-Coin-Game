# Shootouts

Trigger a shootout in every space with terror.

# Bombing

Rats may perform one free bombing (attack option B).

# Politicians

The Government player gets one point for every surviving politician on the map. Then, each space with a politician shifts towards support.

# Score support and resist

Shift points by the net result of the following:
* Government player gets points from each space with support equal to the number of civilian cubes in the space.
* Rats player gets points from each space with resist equal to the number of civilian cubes in the space.

# Emergency Zones

In each emergency zone, if no Rat pieces remain, remove the emergency zone and shift the space towards support. Then, the Rats get one point for each emergency zone still on the map.

# Last round game end

If this is the last propaganda round, the game ends here.

# Resources

Government receives resources from each LOC without sabotage, and from each other space without sabotage equal to the number of civilian cubes in the space.
